# Prediksi-sampah
Membuat prediksi Sampah dalam lingkup Keluarga,RT,RW per-minggu...
Tujuan Proyek : Membuat perhitungan untuk memprediksi Sampah dalam lingkup perorangan,Keluarga,RT,RW dalam rentang waktu per-minggu.
cara menjalankan : Menggunakan python dalam web google colab 
Hyper parameter yang dicoba dan hasil terbaik :
Waktu penelitian LightGBM: 40,10 detik, Metrik MSE LightGBM: 3.8405, Dan R2 Score LightGBM: 87.63%
Keterbatasan : Memprediksi sebatas lingkup kecil RW tidak sampai Kecamatan, Kelurahan, Provinsi.
